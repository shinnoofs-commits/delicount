# **App Name**: SwiftPOS

## Core Features:

- Product Management: Manage products, including name, price, stock, SKU, category, and image.
- Stock Alert: Generate automated stock level warnings using a tool to determine the threshold.
- POS Interface: Touch-friendly UI for adding products to the cart by image or name search using SKU or product name.
- Cart Management: Add, remove, and modify product quantities in the cart. Apply discounts (percentage or amount) and coupons.
- Real-time Calculation: Calculate total amount in real-time, with support for various payment methods (cash, credit card, e-money, QR code, points).
- Sales Tracking: Record each transaction with details like transaction ID, date/time, payment method, total amount, discounts, coupons, sold items (ID, quantity, unit price), and staff ID.
- User and Permissions Management: Create accounts and manage roles (Admin, Employee) with access control for sales, product management, and register operations.

## Style Guidelines:

- Primary color: Soft Blue (#A0D2EB) for a calm, trustworthy feel.
- Background color: Very light gray (#F5F5F5) to ensure clarity and readability.
- Accent color: Orange (#FFA500) to draw attention to important interactive elements.
- Font: 'PT Sans' (sans-serif) for body and headline. This provides a modern yet warm aesthetic suitable for clear and quick readability.
- Simple, clear icons for product categories and functions. Consider using filled icons for primary actions and outlined icons for secondary actions.
- Clean and intuitive layout with clearly defined sections for product display, cart, and payment options. Maximize the use of white space for readability.
- Subtle animations on adding/removing items from the cart and when applying discounts/coupons, to provide a smooth user experience.
